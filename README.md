# apil 0.2.00

Автопилот для District на GTA V b2699.

[Скачать APIL.exe](https://github.com/insurgut/gta-2699-autopilot/raw/refs/heads/main/dist/APIL.exe)

На Windows 10/11 x64 запустите APIL.exe из папки, в которую можно записывать. Включите автоподключение в настройках или нажмите «Подключить» после входа в игровой мир. Извлечённые компоненты, маршруты, настройки и кеш карт хранятся в `%LOCALAPPDATA%\Lisurgut\DistrictAutopilot2699`. Для игрового оверлея нужен оконный режим или режим без рамки.

- Insert включает и останавливает запись, Delete запускает или останавливает проезд, End позволяет выбрать точку продолжения.
- Маршруты открываются после подключения. В маршруте выберите метку ожидания на карте или в списке, чтобы задать дистанцию остановки, интервалы трёх секторов, скорость в каждом секторе и задержку после смещения объекта.
- Проверка обновлений запускается при открытии приложения и затем каждые 15 минут. Статус показан под версией. Проверенная по SHA-256 сборка устанавливается в простое, когда игра вне фокуса и не открыта форма редактирования.
- Совместимость со сборкой игры проверяет профиль b2699. Варианты сборки с отличающимися адресами могут потребовать отдельной диагностики.

## Сборка

Установите MinGW-w64 x86-64 с GCC, windres и Python 3. Запустите `./build-mingw.sh`. Скрипт создаёт `dist/APIL.exe` и `dist/update.txt`. Для публикации следующей версии обновите версию в `src/apil_release.hpp` и опубликуйте оба файла одним коммитом в `main`. Поддерживаемые переменные сборки: `APIL_CXX`, `APIL_WINDRES`.

Атрибуция ассетов и лицензии перечислены в THIRD_PARTY_NOTICES.md и assets/map/NOTICE.md.
