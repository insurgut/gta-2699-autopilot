# apil 0.2.07

Автопилот для District на GTA V b2699.

[Скачать APIL.exe](https://github.com/insurgut/gta-2699-autopilot/releases/latest/download/APIL.exe)

На Windows 10/11 x64 запустите APIL.exe из папки, в которую можно записывать. На старте APIL проверяет наличие WebView2 Runtime. При его отсутствии встроенный установщик Microsoft скачает и установит Runtime, после чего откроется веб-интерфейс из версии 0.1.51. Можно дождаться автоподключения или нажать «Подключить» после входа в игровой мир. Извлечённые компоненты, маршруты, настройки и кеш карт хранятся в `%LOCALAPPDATA%\Lisurgut\DistrictAutopilot2699`. Для игрового оверлея нужен оконный режим или режим без рамки.

- Insert включает и останавливает запись, Delete запускает или останавливает проезд, End позволяет выбрать точку продолжения.
- В конце маршрута на карте показывается один клетчатый флаг в цвет маршрута, с чёрной обводкой и без подложки. Нажатие открывает настройки старта/финиша: игнорирование 0–60 последних секунд (приблизительно по скорости записи) и ожидание 0–300 секунд перед следующим кругом. При включённом повторе, нулевой паузе и близком старте (до 15 м) APIL соединяет укороченный конец со стартом и продолжает круг без финишной остановки и снятия газа ради финиша; проверки препятствий и безопасная скорость в поворотах остаются активными. Настройки сохраняются отдельно у каждого маршрута.
- У каждого объекта ожидания на карте можно настроить задержку, дистанцию остановки, границы и скорости трёх секторов подъезда. При прокрутке карта сворачивается, а список участков остаётся под ней.
- Проверка обновлений запускается при открытии приложения и затем каждые 15 минут. Проверенная по SHA-256 сборка устанавливается в простое, когда игра вне фокуса.
- Совместимость со сборкой игры проверяет профиль b2699. Варианты сборки с отличающимися адресами могут потребовать отдельной диагностики.

В мини-меню объекта ожидания есть схема секторов и быстрые значения задержки. Редактор участка показывает его форму, длину и ограничения. В настройках маршрута доступны палитра и предпросмотр цвета.

## Сборка и обновления

При обновлении исходников достаточно заменить `source/APIL-source.zip` в GitHub. GitHub Actions распаковывает архив, собирает Windows x64 с MinGW-w64, вычисляет SHA-256 EXE, создаёт Release `vX.Y.Z` с `APIL.exe` и записывает `dist/update.txt` и совместимую копию EXE в `main` для старых установок. Ручная сборка: `bash build-mingw.sh` (MinGW-w64 GCC, windres, Python 3).

Приложение проверяет `dist/update.txt` каждые 15 минут и получает новую сборку из Releases по HTTPS с проверкой размера и SHA-256. Запуск и замена исполняемого файла происходят после завершения текущего процесса. Настройки и маршруты остаются в `%LOCALAPPDATA%\Lisurgut\DistrictAutopilot2699`. WebView2 устанавливается встроенным загрузчиком при необходимости.

Исходники, веб-интерфейс, ресурсы, лицензии и установщик WebView2 Runtime находятся в ZIP. Сам бинарник находится в Releases и совместимом `dist/`, а не добавляется пользователем вручную. Атрибуция перечислена в THIRD_PARTY_NOTICES.md и assets/map/NOTICE.md.
